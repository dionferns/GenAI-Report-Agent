# OpenSearch Lambda Integration — Critical Fixes Applied

## Issues Found & Fixed

### 1. **Explicit Document IDs in Bulk Operations** ✅ FIXED
**Problem:** OpenSearch Serverless does NOT support explicit document IDs in bulk operations. The code was sending:
```python
{"index": {"_index": self.index_name, "_id": chunk.id}}
```
This caused 400 errors: `"error": "Explicit document IDs are not supported..."`

**Fix Applied (opensearch_vector.py:62-64):**
```python
# Let AOSS auto-generate IDs
actions.append({"index": {"_index": self.index_name}})
```

---

### 2. **No Error Checking on Bulk Operations** ✅ FIXED
**Problem:** The bulk operation was silent on partial failures. Some chunks might fail to insert without logging.

**Fix Applied (opensearch_vector.py:74-83):**
```python
response = self.client.bulk(body=actions)

# Check for partial failures in bulk operation
if response.get("errors"):
    error_items = [item for item in response["items"] if "error" in item.get("index", {})]
    log.error("bulk_upsert_had_errors", error_count=len(error_items), total=len(chunks), index=self.index_name)
    for error_item in error_items[:5]:
        log.error("bulk_error_detail", error=error_item.get("index", {}).get("error"))
else:
    log.info("chunks_upserted_to_opensearch", count=len(chunks), index=self.index_name)
```

---

### 3. **60-Second Wait Before Reporter** ✅ ALREADY APPLIED
**Problem:** OpenSearch Serverless has ~20-60 second eventual consistency delay. Newly inserted chunks weren't searchable immediately.

**Fix Status:** Already added to ingestion.py:272-279 in reporter_node:
```python
# Wait for OpenSearch Serverless eventual consistency
log.info("reporter_waiting_for_opensearch_consistency", seconds=60, run_id=state.run_id)
time.sleep(60)
```

---

### 4. **Index Refresh Not Supported** ✅ NO ISSUE FOUND
**Problem:** OpenSearch Serverless doesn't support `indices.refresh()`.

**Status:** No refresh calls found in codebase. Not an issue.
